Mỗi nhóm (ví dụ US, UK, JP) giữ một dải port riêng. Proxy thứ 1 trong nhóm ứng với port đầu dải, proxy thứ 2 ứng với port kế tiếp. Thay đổi được áp dụng ngay, không cần restart.

Lấy sock từ ShopSocks5

Gọi lại một IP cũ

Thử nút "Gắn" ở kết quả tìm kiếm hoặc lịch sử trước (không tốn lượt). Nếu proxy cũ đã chết, nhập IP thoát để xin ShopSocks5 cấp lại sock có đúng IP đó (tốn 1 lượt, chỉ được khi IP đó còn trong kho của họ).

Tài khoản ShopSocks5
Danh sách IP loại trừ

Link trả về các IP không được lấy lại (ví dụ IP đã lead). Sock có IP nằm trong danh sách bị bỏ và lấy bù, áp dụng cho mọi nhóm và cả API cho khách; sock bị bỏ vẫn trừ lượt. Bỏ trống rồi Lưu để tắt.

API cho khách: tự đổi IP theo port

Khách gọi link để lấy IP mới cho port của mình (lấy sock mới từ ShopSocks5, tốn 1 lượt) hoặc gọi lại một IP đã dùng. Mỗi port có key riêng nên khách không đụng được port khác.


          
Key dùng chung cho nhiều port

          
Khách thuê nhiều port thì tạo một key cho cả cụm port đó; khách dùng cùng key cho mọi link, chỉ đổi số port.
